# SQL-практика: воронка конверсии

Одна из ранних работ по продуктовой аналитике. В проекте подготовлена таблица событий и написаны SQL-запросы для подсчёта общей конверсии и сравнения этапов воронки по источникам и устройствам.

## Что отрабатывалось

- создание таблицы и проверка данных;
- подсчёт уникальных пользователей;
- конверсия между шагами;
- группировка по источнику и устройству;
- сортировка и фильтрация результатов.

Данные синтетические. Проект оставлен как ранняя SQL-практика; более полный разбор воронки находится в основном проекте `marketplace-search-to-purchase-funnel`.
