# Сравнение двух способов расчёта продуктовых метрик

Небольшая практика по Python и pandas. На событиях условного приложения рассчитываются DAU и число уникальных пользователей по типам событий. Затем сравниваются две реализации: обычные циклы Python и группировки pandas.

## Что внутри

- загрузка и очистка событий;
- расчёт DAU и уникальных пользователей;
- сравнение результатов двух реализаций;
- замеры времени и график DAU;
- простые тесты для проверки совпадения метрик.

Данные искусственные. Здесь не строится полноценная продуктовая воронка: подсчёт пользователей по типам событий не проверяет последовательность переходов.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
python -m pytest -q
```

Замеры производительности зависят от компьютера и размера набора данных. Их стоит воспринимать как результат конкретного запуска, а не как универсальное сравнение Python и pandas.
