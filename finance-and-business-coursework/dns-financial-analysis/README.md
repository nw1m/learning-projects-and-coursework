# Финансовый анализ DNS Retail

Учебная работа по анализу бухгалтерской отчётности ООО «ДНС Ритейл» за 2022–2024 годы. Данные взяты из Государственного информационного ресурса бухгалтерской (финансовой) отчётности; выгрузка в книге сформирована 5 апреля 2025 года.

## Что сделано в Excel

- горизонтальный анализ отчётности;
- вертикальный анализ баланса;
- расчёт коэффициентов ликвидности и финансовой устойчивости;
- анализ оборачиваемости и рентабельности;
- краткая сводка по динамике финансовых результатов.

В книге оставлены листы с исходной информацией, балансом, финансовыми результатами и выводами. Организационные реквизиты относятся к публичной отчётности компании.
