# Учебная DCF-модель в Excel

Модель дисконтированных денежных потоков для пяти условных компаний из разных секторов. Работа показывает связь вводных допущений с прогнозом свободного денежного потока и оценкой стоимости бизнеса.

## Структура книги

- `Допущения` — выручка, темп роста, маржа EBIT, налог, D&A, Capex, оборотный капитал и ставки дисконтирования.
- `DCF` — прогноз FCF на пять лет, дисконтирование и терминальная стоимость.
- `Данные` — таблица FCF по компаниям и годам.
- `Сводная` — сравнение FCF по секторам и оценка EV.

Все компании и значения условные. Результаты нужны для демонстрации механики модели, а не для оценки реальных эмитентов.

## Файлы

- `dcf_model.xlsx` — финансовая модель.
- `build_model.py` — скрипт сборки модели.
