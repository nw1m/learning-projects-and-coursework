# Анализ курса доллара в Excel

Ранняя учебная работа по анализу временного ряда. В книге рассчитаны простые и взвешенные скользящие средние, а также выполнены базовые проверки динамики ряда.

## Файлы

- `usd_rate_analysis.xlsx` — исходная книга с расчётами и диаграммами.
- `images/usd_chart.png` — иллюстрация графика.

Это учебная работа с историческим рядом. В исходных материалах не хватает полной информации о методике отбора дат и источнике каждого наблюдения, поэтому график не следует использовать как актуальную статистику курса.
