# Базовый анализ продаж

Ранняя учебная работа по анализу продаж в Python. Рассчитываются выручка, прибыль, количество заказов и средний чек, затем результаты сравниваются по категориям, регионам и месяцам.

Данные в `data/sales_demo.csv` синтетические и создаются скриптом `src/generate_data.py`. В таблице одна строка соответствует товарной позиции, поэтому средний чек рассчитывается после группировки по заказу.

## Запуск

```bash
pip install -r requirements.txt
python src/generate_data.py
```

Откройте `notebooks/01_sales_analysis.ipynb` и выполните ячейки по порядку. SQL-примеры находятся в `sql/queries.sql`.

Проект оставлен как базовая практика pandas; его можно сравнить с более поздними работами по продуктовым метрикам.
