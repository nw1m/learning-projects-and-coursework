# Структура файлов проекта

## users.csv

| Поле | Описание |
|---|---|
| `user_id` | Уникальный идентификатор пользователя |
| `signup_date` | Дата регистрации |
| `signup_source` | Источник регистрации: organic, paid_ads или referral |

## activity.csv

| Поле | Описание |
|---|---|
| `user_id` | Идентификатор пользователя из `users.csv` |
| `activity_date` | Дата активности |
| `event_name` | Тип события: session, search или content_view |

У одного пользователя может быть несколько событий в одном месяце. При расчёте retention используются уникальные пользователи. Данные искусственные.
