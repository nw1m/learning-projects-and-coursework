# Когортный анализ удержания пользователей

Учебная работа по когортному retention. Пользователи группируются по месяцу регистрации, после чего рассчитывается доля участников каждой когорты, которые возвращались в следующие месяцы. Результат показан в виде heatmap.

## Что сделано

- определён месяц регистрации пользователя;
- события связаны с таблицей пользователей;
- рассчитаны размеры когорт и активные пользователи;
- построена матрица retention и тепловая карта.

Данные синтетические. В реальном продукте отдельно нужно определить событие активности и учитывать неполные периоды наблюдения у новых когорт. Эта работа сохранена как дополнительная практика по когортному анализу.

## Запуск

Откройте `analysis.ipynb` и выполните ячейки сверху вниз.
