# SQL-анализ продаж интернет-магазина

Учебный проект по работе с реляционной базой SQLite. В базе четыре связанные таблицы: клиенты, товары, заказы и позиции заказов.

## Что сделано

- Собрана база из CSV-файлов с помощью Python.
- Написаны запросы для расчёта выручки, среднего чека и количества заказов.
- Добавлены JOIN, GROUP BY, HAVING, подзапросы и CASE WHEN.
- Рассмотрены продажи по категориям, клиентским сегментам и месяцам.

## Данные

Данные синтетические и создаются скриптом `build_database.py` с фиксированным seed. Это учебный пример, а не выгрузка реального магазина.

## Запуск

```bash
python build_database.py
sqlite3 shop.db < queries.sql
```

`shop.db` уже приложена, поэтому можно начать с запросов в `queries.sql`.
