# Воронка onboarding мобильного приложения

Учебная работа по расчёту простой воронки регистрации. Рассматриваются четыре шага: посещение страницы, регистрация, заполнение профиля и первое целевое действие.

## Что сделано

- проверены события и структура таблицы;
- посчитаны уникальные пользователи на каждом шаге;
- рассчитаны конверсии и потери между этапами;
- сравнен переход к первому действию по источникам;
- подготовлены графики и базовые SQL-запросы.

`data/events_demo.csv` содержит синтетические учебные события. Сравнение источников носит описательный характер и не объясняет причины различий.

## Запуск

Установите зависимости из `requirements.txt`, откройте `notebooks/01_onboarding_funnel.ipynb` и выполните ячейки сверху вниз.
