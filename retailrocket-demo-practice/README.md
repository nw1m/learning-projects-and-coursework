# Анализ событий интернет-магазина: RetailRocket

Ранний учебный проект по анализу пользовательских событий. В нём рассматриваются типы действий, упрощённая воронка на уровне посетителя, недельный retention и популярные товары.

## Важное замечание о данных

В репозитории хранится демонстрационный синтетический CSV, а не полный оригинальный датасет RetailRocket. Поэтому числа и выводы из текущего запуска относятся только к демонстрационной выборке. В проекте есть скрипт для получения исходных данных; перед использованием результатов в резюме нужно скачать оригинальный набор и повторно выполнить анализ.

## Что анализируется

- распределение событий;
- переходы от просмотра к добавлению в корзину и покупке;
- недельный retention;
- товары с наибольшим количеством событий покупки.

Воронка упрощённая: действия могут происходить в разные дни и не обязательно с одним товаром. Частота событий покупки не равна выручке.
