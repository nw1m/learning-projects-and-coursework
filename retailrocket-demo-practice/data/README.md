# Данные

`demo/events_demo.csv` — искусственная мини-выборка для проверки пайплайна. Она не является частью оригинального Retail Rocket dataset.

Для основного анализа скачайте Retailrocket recommender system dataset: https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset

Положите оригинальный файл `events.csv` в `data/raw/events.csv`. Не загружайте большой исходный файл в публичный GitHub-репозиторий без проверки условий распространения датасета.
