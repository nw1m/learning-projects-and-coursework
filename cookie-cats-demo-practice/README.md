# A/B-тест Cookie Cats: учебный разбор

Проект посвящён сравнению Day-7 retention у игроков, которым первые игровые ворота показывались на 30-м или 40-м уровне. В ноутбуке есть проверка данных, сравнение долей, доверительный интервал и дополнительные метрики игровой активности.

## Важное замечание о данных

В репозитории приложена демонстрационная синтетическая выборка. Это не оригинальный публичный датасет Cookie Cats, поэтому текущие значения нельзя выдавать за результаты известного эксперимента. Скрипт загрузки оставлен в `src/`; после получения исходного файла можно повторить расчёты.

## Методы

- проверка состава групп и пропусков;
- проверка SRM;
- сравнение Day-7 retention;
- доверительный интервал и bootstrap;
- дополнительное сравнение Day-1 retention и числа игровых раундов.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook
```

Откройте `notebooks/01_ab_test_analysis.ipynb`. Для корректной интерпретации результатов сначала проверьте источник данных, указанный в ноутбуке.
